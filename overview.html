System Overview

How the System Works

A complete picture of the Touchless HMS architecture, actor roles, data flow, and technology stack.

User Roles

System Actors

Four primary user personas interact with the system through different interfaces depending on their environment.

👨‍⚕️

Surgeon

Touchless Only

Operates entirely via Leap Motion in the OR. Views patient vitals, records, and imaging hands-free.

👩‍⚕️

Nurse

Touchless (Ward)

Manages patient alarms, medication schedules, and ward displays using gesture control.

🧑‍⚕️

Doctor

Hybrid

Uses traditional touch in clinics for appointments and prescriptions; touchless in sterile areas.

🧑

Outpatient

Touch / Mobile

Books appointments and views results through the Flutter patient mobile app.

Technology

Technology Stack

✋

Leap Motion SDK

Infrared 3D skeletal tracking of hands at 120fps for sub-millimeter gesture accuracy.

Hardware Input
🐍

Python Middleware

Processes raw Leap Motion data via the official SDK, classifies gestures, and emits events over WebSocket.

Backend Logic
💙

Flutter Frontend

Cross-platform UI framework for both the patient app and the OR touchless dashboard with real-time updates.

Frontend
🔥

Backend / DB
🔔
