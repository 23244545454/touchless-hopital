Sequence Diagram

sequenceDiagram actor Surgeon participant LM as Leap Motion participant PY as Python Middleware participant WS as WebSocket Server participant FL as Flutter Dashboard participant FB as Firebase Firestore Surgeon->>LM: Perform gesture (swipe right) LM->>PY: Raw skeleton data (3D coordinates) PY->>PY: Classify gesture type PY->>WS: Emit {gesture: "swipe_right", confidence: 0.94} WS->>FL: WebSocket message received FL->>FB: Fetch next patient record FB-->>FL: Patient data (JSON) FL->>FL: Render updated UI FL-->>Surgeon: Visual feedback (highlight) + Audio beep Note over FL: Zero physical contact required
